# Оболочка приложения и игровой хост

## Зачем разделено

Стартовый экран (`components/StartScreen.tsx`) не нуждается ни в игре, ни в её хуке. Раньше
`App.tsx` был одновременно и стартовым экраном, и игрой, поэтому браузер скачивал `useGameLogic`,
`utils/responseProcessor.ts` и все менеджеры до того, как игрок нажмёт «Begin Your Adventure».

Теперь:

| Слой | Файл | Что внутри | Когда грузится |
|---|---|---|---|
| Оболочка | `App.tsx` | `StartScreen`, `useStartScreenStatus`, панель GM-реле, обработчики `window.error`/`unhandledrejection` | всегда |
| Игровой хост | `components/GameHost.tsx` (`React.lazy`) | `useGameLogic`, `responseProcessor`, игровой UI, 12 ленивых экранов | после старта новой игры или загрузки сохранения |

Оболочка передаёт хосту один запрос — `GameStartRequest`:

```ts
{ kind: 'new', creationData } | { kind: 'file' } | { kind: 'autosave' }
| { kind: 'crashRecovery' } | { kind: 'interruptedTurn' }
| { kind: 'discardInterruptedTurn' } | { kind: 'slot', slotId }
```

Хост выполняет его один раз (см. эффект с `requestHandledRef`), сообщает результат через
`onSettled(started)`. При `started === false` (отмена диалога файла, неудачная загрузка,
отброшенный прерванный ход) оболочка снова показывает стартовый экран и перечитывает его статус.

## Что осталось в оболочке

- Статус стартового экрана: автозапись, crash-recovery, прерванный ход, слоты БД — `hooks/useStartScreenStatus.ts`.
- Миграция base64-картинок из старых сохранений в хранилище изображений — выполняется в оболочке
  до чтения статуса, потому что это задача старта, а не игрового цикла.
- Автозагрузка по `consumeStartupLoadRequest()` (`'crashRecovery'` или `'autosave'`): оболочка
  превращает флаг в запрос `kind: 'crashRecovery' | 'autosave'`, поэтому после перезагрузки игрок
  сразу попадает в игру, минуя стартовый экран.

## Проверки

- `scripts/app-chunk-split.test.mjs` — оболочка не импортирует хук и обработчик хода, в хосте
  статически нет ни одного игрового экрана.
- `e2e/in-game-chunk-split.spec.ts` — в браузере: на стартовом экране не запрашивается чанк
  `GameHost-*.js` и ни в одном скачанном бандле нет литерала `Step3_Logs` из игрового ядра; после
  загрузки сохранения чанк грузится.
- `e2e/game.spec.ts` — новая игра проходит путь «форма → запрос → хост».
- `e2e/save-images.spec.ts` — миграция картинок при старте и автозагрузка автозаписи без клика.
